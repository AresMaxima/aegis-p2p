# Security Policy & Hall of Fame

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.2-GA  | :white_check_mark: |

## Reporting a Vulnerability
Send details to security@aresmaxima.org or open a PGP-encrypted issue.

## Bug Bounty & Hall of Fame
Zero-day vulnerabilities, cryptographic flaws, or TEE bypasses will be rewarded with:
- Attribution in the Hall of Fame.
- Assigned CVE credits.
