AEGIS P2P

Guide d'Opération & Manuel OpSec — Architecture Zero-Persistence

SECTION 1 : Principes de Sécurité & Démarrage à Froid

Architecture Zero-Persistence : AEGIS fonctionne exclusivement en mémoire vive (RAM). Aucune clé, aucun historique et aucun cache ne sont écrits sur le disque. Dès la fermeture de l'application ou l'extinction de l'appareil, les données sont définitivement détruites.

Mécanisme de Déverrouillage & PIN Dynamique :

Clef Principale (Accès Réel) Code PIN dynamique de session défini par l'opérateur.
Code de Contrainte (PIN Leurre) N'IMPORTE QUEL autre PIN valide redirige vers un tableau leurre ("Notes").
Code de Panique (Kill Switch) 0000 (ou erreurs répétées) — Efface la RAM et stoppe le processus.
  • Protection Anti-Capture (FLAG_SECURE) : Bloque matériellement les captures d'écran, les enregistrements vidéo et masque l'aperçu dans le sélecteur d'applications Android.
  • Minuteur d'Inactivité : Après 3 minutes sans interaction, la mémoire RAM est purgée et l'application se ferme automatiquement.

SECTION 2 : Échange de Clés & Connexion P2P

Identité Éphémère : Votre identité réseau est représentée par votre Clé Publique (Ed25519/X25519) générée en RAM.

Établir une connexion :

  • En face-à-face : Appuyez sur MON QR CODE. Votre correspondant appuie sur SCANNER UN QR CODE pour initialiser la poignée de main E2EE.
  • À distance : Appuyez sur COPIER MA CLÉ et transmettez-la via un canal secondaire. Le destinataire la colle dans le champ "Clé Publique du destinataire" puis clique sur CONNECTER LE PAIR.

SECTION 3 : Commutateur de Transport Réseau (Transport Switch)

  • Tor v3 Embarqué (Anonymat Max) : Lance un service masqué .onion local. Masque l'adresse IP et traverse les pare-feux stricts.
  • Direct WAN (P2P / DHT Rapide) : Connexion directe inter-appareils via Kademlia DHT/STUN pour un débit maximal.
  • Hors-Ligne / Local (LAN / Bluetooth) : Fonctionne sans réseau Internet via Wi-Fi local ou Bluetooth Mesh pour les réunions physiques.
  • Hybride / Auto (Saut de Fréquence) : Basculement dynamique entre les transports avec détection de la censure et activation automatique des ponts Snowflake / WebRTC.

SECTION 4 : Module Stéganographique & Urgence

  • Noyer une clé dans un texte : Saisissez une clé ou une phrase dans le module Stéganographie et cliquez sur NOYER LA CLÉ DANS UN POÈME.
  • Extraire une clé : Collez le texte stéganographique reçu et cliquez sur EXTRAIRE LA CLÉ DU TEXTE pour charger le destinataire.
  • Destruction Immédiate : Dans le panneau d'urgence, cliquez sur DESTRUCTION IMMÉDIATE DE LA RAM (KILL SWITCH) pour purger la mémoire sans laisser de trace.
