РОЗДІЛ 1: Принципи безпеки та холодний запуск

Архітектура нульової персистентності: AEGIS працює виключно в оперативній пам'яті (RAM). Жодні ключі, історія чатів або файли кешу не записуються на накопичувач. При закритті застосунку або вимкненні пристрою всі дані сеансу безповоротно знищуються.

Механізм розблокування та динамічний PIN:

Основний ключ (Реальний доступ) Динамічний PIN-код сеансу, визначений оператором.
Код примусу (PIN-приманка) БУДЬ-ЯКИЙ інший валідний PIN відкриває фальшиву панель ("Нотатки").
Панічний код (Kill Switch) 0000 (або повторювані помилки) — Очищає RAM і закриває.
  • Захист від знімків екрана (FLAG_SECURE): На апаратному рівні блокує скриншоти, відеозапис і приховує передперегляд застосунку у меню останніх програм Android.
  • Тайм-аут бездіяльності: Через 3 хвилини відсутності дій користувача оперативна пам'ять автоматично очищається, і застосунок завершує роботу.

РОЗДІЛ 2: Обмін ключами та P2P-з'єднання

Ефемерна ідентичність: Ваша мережева ідентичність визначається ефемерним публічним ключем (Ed25519/X25519), згенерованим у RAM.

Встановлення з'єднання:

  • Особисто: Натисніть МІЙ QR-КОД. Ваш співрозмовник натискає СКАНУВАТИ QR-КОД для ініціалізації E2EE-рукостискання.
  • Дистанційно: Натисніть СКОПІЮВАТИ МІЙ КЛЮЧ і надішліть його резервним каналом. Отримувач вставляє його в поле "Публічний ключ отримувача" та натискає ПІДКЛЮЧИТИ ПІР.

РОЗДІЛ 3: Перемикач мережевого транспорту

  • Вбудований Tor v3 (Максимальна анонімність): Запускає локальний прихований сервіс `.onion`. Приховує вашу IP-адресу та обходить суворі брандмауери.
  • Прямий WAN (Швидкий P2P / DHT): Встановлює прямі з'єднання між пристроями через Kademlia DHT/STUN для максимальної швидкості.
  • Офлайн / Локально (LAN / Bluetooth): Працює без підключення до Інтернету через локальний Wi-Fi або мережу Bluetooth Mesh для особистих зустрічей.
  • Гібридний / Авто (Стрибок частоти): Динамічне перемикання між транспортами з активним виявленням цензури та автоматичною активацією мостів Snowflake / WebRTC.

РОЗДІЛ 4: Стеганографічний модуль та екстрена допомога

  • Сховати ключ у тексті: Введіть ключ або повідомлення у модуль стеганографії та натисніть СХОВАТИ КЛЮЧ У ВІРШІ, щоб замаскувати його у невинному тексті.
  • Витягти ключ: Вставте отриманий стеганографічний текст і натисніть ВИТЯГТИ КЛЮЧ З ТЕКСТУ для автоматичного завантаження піра.
  • Негайне знищення: На панелі безпеки натисніть НЕГАЙНЕ ОЧИЩЕННЯ RAM (KILL SWITCH), щоб очистити пам'ять і завершити процес без слідів.
