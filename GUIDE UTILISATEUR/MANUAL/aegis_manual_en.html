AEGIS P2P

Operation Guide & OpSec Manual — Zero-Persistence Architecture

SECTION 1: Security Principles & Cold Boot

Zero-Persistence Architecture: AEGIS operates exclusively in volatile memory (RAM). No keys, chat history, or cache files are ever written to local storage. Upon closing the application or powering off the device, all session data is permanently destroyed.

Unlocking Mechanism & Dynamic PIN:

Master Key (Real Access) Dynamic session PIN code set by the operator.
Duress Code (Decoy PIN) ANY other valid PIN redirects to a decoy dashboard ("Notes").
Panic Code (Kill Switch) 0000 (or repeated errors) — Purges RAM and terminates process.
  • Anti-Capture Protection (FLAG_SECURE): Hardware-blocks screenshots, video recordings, and hides app preview in Android's recent apps switcher.
  • Inactivity Timeout: After 3 minutes without user interaction, allocated RAM is automatically purged and the application terminates.

SECTION 2: Key Exchange & P2P Connection

Ephemeral Identity: Your network identity is defined by an ephemeral Public Key (Ed25519/X25519) generated in RAM.

Establishing a Connection:

  • In-Person: Tap MY QR CODE. Your contact taps SCAN QR CODE to initialize the E2EE handshake.
  • Remote: Tap COPY MY KEY and send it via a secondary channel. The recipient pastes it into "Recipient Public Key" and taps CONNECT PEER.

SECTION 3: Network Transport Switch

  • Embedded Tor v3 (Max Anonymity): Starts a local .onion hidden service. Hides your IP address and bypasses restrictive firewalls.
  • Direct WAN (Fast P2P / DHT): Establishes direct device-to-device connections via Kademlia DHT/STUN for maximum throughput.
  • Offline / Local (LAN / Bluetooth): Operates without an Internet connection via local Wi-Fi or Bluetooth Mesh network for face-to-face meetings.
  • Hybrid / Auto (Frequency Hopping): Dynamic failover between transports with active censorship detection and automatic Snowflake / WebRTC bridge activation.

SECTION 4: Steganography Module & Emergency

  • Hide Key in Text: Enter a key or message in the steganography module and click EMBED KEY IN POEM to disguise it within innocent text.
  • Extract Key: Paste the received steganographic text and click EXTRACT KEY FROM TEXT to automatically load the peer.
  • Immediate Destruction: In the security panel, tap IMMEDIATE RAM PURGE (KILL SWITCH) to wipe memory and terminate the process without leaving a trace.
