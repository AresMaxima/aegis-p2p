AEGIS P2P

Guide d'Opération & Manuel OpSec — Résilience & Anonymat

SECTION 1 : PRINCIPES DE SÉCURITÉ & DÉMARRAGE

Zéro-Persistence des Secrets : AEGIS ne stocke jamais votre master_key, vos clés de session ou l'historique de vos conversations sur le disque. Toutes ces données sensibles résident exclusivement en mémoire vive (RAM). Un fichier chiffré (vault.json) est utilisé uniquement pour stocker un sel cryptographique et un vérificateur HMAC, qui ne permettent pas de retrouver vos clés.

Déverrouillage & Codes de Sécurité : Au premier lancement, vous définissez un PIN fort (6+ caractères). Ce PIN est utilisé pour dériver votre master_key via HKDF-SHA256. Vous pouvez configurer un second PIN (mode leurre) qui ouvrira un tableau de bord factice.

PIN Principal Votre choix — Ouvre le tableau de bord réel.
PIN Leurre (Decoy) Votre choix — Ouvre un faux tableau de bord ("Notes").
Kill Switch 0000 ou 9999 — Purge la RAM et ferme l'application.
  • Protection Anti-Capture (FLAG_SECURE) : Empêche les captures d'écran, les enregistrements vidéo et masque l'aperçu de l'application dans le sélecteur de tâches Android.
  • Verrouillage Automatique : Après 1 minute d'inactivité, la RAM est purgée et l'application se ferme.

SECTION 2 : ÉCHANGE DE CLÉS & CONNEXION P2P

Identité P2P Dérivée : Votre identité sur le réseau est une clé publique ed25519, dérivée de manière déterministe à partir de votre master_key via HKDF-SHA256. Elle est donc unique, éphémère (change si le PIN change) et ne nécessite aucun stockage supplémentaire.

Établir une connexion :

  • En face-à-face : Appuyez sur MON QR CODE. Votre correspondant scanne le code avec SCANNER UN QR CODE pour initier la poignée de main E2EE.
  • À distance : Appuyez sur COPIER MA CLÉ et transmettez-la via un canal secondaire. Le destinataire la colle dans le champ "Clé Publique du destinataire" puis clique sur CONNECTER LE PAIR.

SECTION 3 : COMMUTATEUR DE TRANSPORT RÉSEAU (TRANSPORT SWITCH)

AEGIS peut router vos messages via trois transports chiffrés, sélectionnables manuellement ou automatiquement :

  • Tor (Anonymat Max) : Utilise un client Tor intégré (Arti) pour se connecter au réseau Tor et accéder à des adresses .onion. Masque votre adresse IP et contourne la censure. (Latence plus élevée).
  • Direct (P2P) : Connexion directe TCP/UDP entre pairs via leur adresse IP (avec STUN pour la découverte). Offre le meilleur débit, mais expose votre IP au pair (si vous n'êtes pas derrière Tor).
  • Hors-Ligne / Local (LAN / Bluetooth) : Fonctionne sans Internet via Wi-Fi Direct ou BLE Mesh pour les réunions physiques.
  • Mode Hybride (Auto) : Bascule automatiquement entre Tor, Wi-Fi Direct et BLE Mesh en fonction de la disponibilité du réseau et de votre politique de sécurité.

SECTION 4 : MODULE STÉGANOGRAPHIQUE & URGENCE

  • Noyer une clé dans un texte : Cachez une clé ou une phrase dans le module Stéganographie et cliquez sur NOYER LA CLÉ DANS UN POÈME.
  • Extraire une clé : Collez le texte stéganographique reçu et cliquez sur EXTRAIRE LA CLÉ DU TEXTE pour charger le destinataire.
  • Destruction Immédiate : Dans le panneau d'urgence, cliquez sur DESTRUCTION IMMÉDIATE DE LA RAM (KILL SWITCH) pour purger la mémoire sans laisser de trace.

SECTION 5 : TRAITEMENT MÉDIA SÉCURISÉ (ZÉRO-DISQUE)

Ingestion Zéro-Disque : Toutes les photos, vidéos et documents que vous importez dans AEGIS sont traités exclusivement en mémoire vive (RAM) via le module aegis_ingest_file_zero_disk(). Aucun fichier temporaire n'est créé sur le stockage de l'appareil. Le contenu est détruit à la fermeture de l'application.

Sécurité de la RAM (Polymorphic RAM) : Les buffers qui contiennent vos médias en RAM sont protégés par un masque XOR dynamique (à offset aléatoire) et une structure "dual rail" (deux copies avec canaris d'intégrité). Cela empêche la lecture directe de la mémoire (cold boot, dump RAM) et détecte toute altération (bit-flip).

  • Anti-PRNU : Les images capturées par l'appareil photo (CameraX) sont traitées pour atténuer les motifs PRNU (Photo Response Non-Uniformity). C'est une empreinte unique du capteur qui pourrait identifier le téléphone lors d'une analyse forensic.
  • Stripping EXIF : Toutes les métadonnées (géolocalisation, modèle d'appareil, horodatage) sont supprimées des images avant tout partage.
  • Visionneuse "Blind" : Le contenu est affiché via une surface VRAM isolée (BlindView). L'aperçu est masqué dans le sélecteur de tâches, et les captures d'écran sont bloquées par le FLAG_SECURE global.
  • Scellement Sécurisé (Optionnel) : Si vous choisissez de persister un média sur le disque (via aegis_seal_ram_to_disk()), le flux est d'abord converti de YUV420 vers RGBA, puis encodé en JPEG (qualité 85) entièrement en RAM, avant d'être écrit. Aucun fichier brut n'est laissé sur le disque.
